How It Works

POST /stories/generate
  body: { "language": "hi", "childId": 13, "goal": "friendship", ... }
       ↓
Backend resolves language:
  1. body.language = "hi" → use it (explicit selection)
  2. (if not sent) child.preferred_language → use it
  3. (if neither) default = "en"
       ↓
Prompt: "Write the ENTIRE story in Hindi language."
       ↓
LLM generates story in Hindi (Devanagari script)
       ↓
Saved to DB: language="hi"
       ↓
Response: { "language": "hi", "title": "नन्हे दोस्तों की प्यारी रात", ... }

Language Resolution Priority

  1. Explicit selection (body.language) — overrides everything
  2. Child profile (child.preferred_language) — fallback if not explicitly set
  3. Default ("en") — final fallback

DB Mode Enhancement

In “db” mode, the query filters by language too:

_query = _select(Story).where(
    Story.goal == body.goal,
    Story.theme == body.theme,
    Story.language == resolved_language,  # ← ensures Hindi request gets Hindi story
)
