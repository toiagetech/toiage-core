Here's the complete API summary — all 17 endpoints with URLs and one-liner descriptions:

Auth (6)

Method URL Description
POST /auth/login Login with email and password
POST /auth/register Register a new parent account
POST /auth/forgot-password Request a password reset link
POST /auth/logout Logout the current user
POST /auth/refresh-token Refresh the access token using a refresh token
GET /auth/profile Get the current user's profile

Parents (3)

Method URL Description
POST /parents Create a parent profile after registration
GET /parents/profile Get the current parent's profile
PUT /parents/profile Update the current parent's profile

Children (6)

Method URL Description
POST /children Create a new child profile
GET /children Get all children for the current parent
GET /children/{childId} Get a specific child's details
GET /children/{id} Get a child by ID (legacy mock UI)
PUT /children/{id} Update a child by ID
DELETE /children/{id} Delete a child by ID

Stories (1)

Method URL Description
POST /stories/generate Generate a personalized AI story based on parent-selected goal, mood, length, theme, and today's context

Dashboard (1)

Method URL Description
GET /dashboard Get the parent dashboard aggregate data (welcome, active child, recommendations, activities, learning journey, quick actions)

Total: 17 endpoints — all have static endpoint.json, request.json (where applicable), and response.json files in src/shared/mock/api/.
