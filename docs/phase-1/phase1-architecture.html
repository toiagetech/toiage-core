Toiage Core

Phase 1 — Backend Architecture Overview

Goal

Build a modular AI-powered backend that generates stories, hands-on activities, and positive reflections on children's artwork — designed for frontend integration and future recommendation systems.

6 Core Features

Feature 1

Prompt Loading System

Externalize all AI prompts so they can be versioned, edited, and reused without touching service code.

POST /ai/test-template
Feature 2

Story Generation & Storage

Generate children's stories and save them with metadata (age_group, theme, skills, difficulty) for future recommendations.

POST /stories · GET /stories · GET /stories/{id}
Feature 3

Activity Generation

Turn any story into a hands-on real-world activity. Supports household mode (common items) and toy-kit mode.

POST /activities/generate · GET /activities · GET /activities/{id}
Feature 4

Image Upload

Upload children's artwork with file validation (jpeg/png/webp/gif, max 10MB). UUID-based local storage.

POST /uploads/image · GET /uploads/files/{name}
Feature 5

AI Image Reflection

Give children positive, encouraging AI feedback on artwork — always warm, never judgmental. Vision-capable model support.

POST /uploads/{id}/reflect
Feature 6

Production Foundation

Structured JSON logging, centralized error handling, PostHog analytics (with log fallback), Alembic migrations, clean startup.

GET /health · GET /db-health
