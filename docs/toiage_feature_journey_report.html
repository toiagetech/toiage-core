Toiage — Product Feature Journey

This document acts as the single source of truth for Toiage feature evolution and product direction.

Phase-1.1 — AI Story & Activity Foundation

Summary

  • Real LLM integrations completed
  • Story generation APIs available
  • Activity generation workflows added
  • Regression and validation setup completed
  • Foundation for future AI workflows established

AI Story Generation

Generate child-friendly stories using AI with categories, themes and character personalization.

  • Bedtime stories
  • Festival stories
  • Adventure stories
  • Science-themed stories

AI Activity Generation

Generate hands-on learning activities connected with stories and learning concepts.

  • Farm model creation
  • Traffic signal activity
  • Water conservation activities
  • Simple STEM builds

Character Personalization

Parents can choose preferred characters and storytelling styles.

  • Mahabharat characters
  • Scientists
  • Fantasy explorers
  • Animal heroes

Phase-2 — Personalized Learning & Project Ecosystem

Summary

  • Child profiles introduced
  • Persistent child world added
  • Science project ecosystem begins
  • Parent insights introduced
  • Guided school project workflows added

Child Profiles

Store child interests, age, preferences and learning behavior for personalization.

Persistent Child World

Activities and stories evolve over time instead of being one-time experiences.

  • Growing farm world
  • Returning characters
  • Long-term learning journeys

Science Project Ecosystem

Expand activities into school science and STEM project workflows.

  • Drip irrigation
  • Traffic management
  • Water cycle
  • Eco city
  • Solar system

AI Parent Insights

Generate insights about creativity, curiosity and learning interests.

Project Presentation Guidance

Help children explain and present projects in schools.

Phase-3 — Knowledge Intelligence & RAG Ecosystem

Summary

  • Document upload workflows introduced
  • Knowledge-grounded generation added
  • Curriculum-aware projects supported
  • Teacher knowledge systems introduced
  • Smart retrieval-based learning enabled

Document Upload System

Parents and schools upload project references and educational materials.

RAG-Based Project Generation

Retrieve relevant educational content before generating projects or stories.

  • CBSE-aligned projects
  • Age-appropriate activities
  • Safe material recommendations

Teacher Knowledge Libraries

Schools can upload teaching materials and classroom activity documents.

Knowledge-Based Storytelling

Stories become grounded in uploaded educational or cultural content.

Semantic Search & Learning Memory

Search and reuse stories, projects and activities using contextual understanding.

Phase-4 — School & B2B Learning Platform

Summary

  • Teacher productivity workflows added
  • Parent engagement systems introduced
  • Printable learning content enabled
  • Seasonal learning packs supported
  • B2B school ecosystem expanded

Teacher Activity Generator

Generate classroom activities, STEM exercises and storytelling sessions quickly.

Parent Communication System

Generate daily learning summaries and activity reports for parents.

Printable Learning Packs

Generate worksheets, project guides and educational activity sheets.

Seasonal Learning Packs

Generate themed educational content for festivals and school events.

  • Diwali activities
  • Earth Day projects
  • Space Week STEM content

Final Strategic Direction

Toiage is evolving into an AI-powered learning-by-building ecosystem combining:

  • Stories
  • Activities
  • Science projects
  • Personalized learning
  • Physical kits
  • Knowledge-grounded AI
  • School enablement workflows
